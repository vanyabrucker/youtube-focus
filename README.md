# YouTube Focus

I use this on MacOS Sonoma in Safari.

I like YouTube and I am fine watching ads but I dislike the homepage feed, I dislike the recommendation bar next to a video, I dislike teaser bars. This repo contains instructions on how to say byebye to those elements in three simple (and free) steps.

## Setup Instructions

### 1. Install Userscripts
Download the **Userscripts** extension from the Mac App Store (Free). Once installed, ensure it is enabled in **Safari Settings > Extensions**.

### 2. Access the Extension
Click the Userscripts icon (`</>`) in your Safari toolbar and click the **"Open Extension Page"** button.

### 3. Create the Filter
1. Create a **New CSS file** within your Userscripts folder (e.g., `youtube-focus.css`).
2. Copy the contents from `youtube-focus.css` in this repository and paste them into your new file.
3. Save the file and refresh YouTube.

Enjoy!
